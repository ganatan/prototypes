### Installation

Télécharger et exécuter :

https://rustup.rs

```text
rustup-init.exe
```

Accepter si nécessaire l’installation des prérequis Visual Studio :

```text
Développement Desktop en C++
MSVC
Windows SDK
```

Choisir :

```text
1) Proceed with standard installation
```

Rouvrir le terminal puis vérifier :

```powershell
rustc --version   # Compilateur Rust
cargo --version   # Gestionnaire de projets, dépendances et builds
rustup --version  # Gestionnaire des versions et toolchains Rust
```
