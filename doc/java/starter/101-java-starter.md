# Java Starter

## Vérification Java

```bash
java -version
javac -version
```

## Création projet IntelliJ

```text
Name: java-starter
Build system: IntelliJ
JDK: 21
```

## Structure

```text
java-starter
└─ src
   └─ Main.java
```

## Main.java

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("java-starter");
    }
}
```

## Exécution

```text
java-starter
```

## Compilation manuelle

```bash
javac Main.java
java Main
```
